# Discord消息转发 · 使用说明

把 Discord 频道的新消息按**规则**转发到两类去向，两者可同时用：

- **MoviePilot 通知渠道**：微信 / Telegram / Slack / Bark 等
- **另一个 Discord 频道**（v4.3.0 新增）：把 A 服务器的发码频道汇总到自己服务器的频道

典型场景：游戏官方礼包码频道转微信、社区公告汇总、把散落在多个服务器的频道并到一个自建频道里统一看。

---

## 一、准备 Discord Bot（第一次用必看）

插件靠一个**你自己的 Bot** 去读消息，所以要先在 Discord 开发者后台建一个。全程 5 分钟，不需要写代码。

### 1. 建 Application

打开 [Discord Developer Portal](https://discord.com/developers/applications) → 右上角 **New Application** → 填个名字（随便起，例如 `MP-Forward`）→ 勾同意 → **Create**。

### 2. 建 Bot 并拿 Token

左侧菜单 **Bot**：

1. 部分账号需要先点 **Add Bot** → **Yes, do it!**（新版后台已自动创建，没有这个按钮就跳过）
2. 点 **Reset Token** → **Yes, do it!** → 复制出现的那串 Token

> ⚠️ **Token 只显示这一次**，关掉页面就再也看不到了，先粘到记事本。
> Token 等同于 Bot 的账号密码，**不要发到群里、不要提交进 Git 仓库**。泄露了就回来点 **Reset Token** 重置，旧的立即失效。

### 3. 打开 MESSAGE CONTENT INTENT（最容易漏的一步）

还在 **Bot** 页面，往下滚到 **Privileged Gateway Intents**：

| 开关 | 是否必须 | 说明 |
|---|---|---|
| **MESSAGE CONTENT INTENT** | ✅ **必须打开** | 不开的话插件能拉到消息，但**正文全是空的**，只能看到 Embed |
| PRESENCE INTENT | ❌ 不用 | |
| SERVER MEMBERS INTENT | ❌ 不用 | |

打开后一定要点页面底部的 **Save Changes**。

> Bot 加入的服务器超过 100 个时，这个开关需要 Discord 官方审核。自用 Bot 远达不到，直接开即可。

### 4. 生成邀请链接，把 Bot 拉进服务器

左侧菜单 **OAuth2** → **URL Generator**：

**Scopes** 只勾一个：

- ✅ `bot`

**Bot Permissions** 按需要勾（中文界面显示为「机器人权限」，下表给了中英对照）：

| 分组 | 中文界面 | 英文界面 | 什么时候需要 |
|---|---|---|---|
| 通用权限 | **查看频道** | View Channels | ✅ 必须。不勾读不到任何频道 |
| 文本权限 | **阅读消息历史记录** | Read Message History | ✅ 必须。插件靠翻历史消息找新消息 |
| 文本权限 | **发送消息** | Send Messages | 只在用**频道 → 频道转发**时需要，转发到通知渠道不用 |
| 文本权限 | **嵌入链接** | Embed Links | 可选。想让转发出去的图片/链接出预览就勾 |
| 文本权限 | **在子区内发送消息** | Send Messages in Threads | 只在转发目标是**子区 / 论坛帖**时需要 |

> Discord 中文把 thread 译成**「子区」**，找 Send Messages in Threads 时按这个词找。
>
> **其余权限一个都不要勾，尤其是「管理员」**。它一次性给全部权限，图省事勾上等于把服务器控制权交给这个 Bot。语音权限全都用不到。
>
> 只做「转发到通知渠道」的话，其实只要**查看频道 + 阅读消息历史记录**两个。

勾完页面最下方会生成一条 **Generated URL**，复制到浏览器打开 → 选择要加入的服务器 → **授权**。

> 只有**你有「管理服务器」权限的服务器**才能把 Bot 拉进去。别人的服务器见下面第 6 节。

权限是写死在邀请链接里的。以后要加权限，重新生成一次 URL 再授权一遍即可（Bot 不会被踢，是覆盖更新）。也可以不改邀请链接，直接在目标频道的 **频道设置 → 权限** 里单独给这个 Bot 加「发送消息」—— 想把发言权限限制在某一个频道时这样更干净。

### 5. 拿频道 ID（一般不需要手填）

填好 Token 保存后，插件会自动拉取 Bot 可见的全部文字/公告频道，配置页直接下拉勾选即可，**通常不用手动找 ID**。

只有下拉列表里没有的频道（**线程、论坛帖子**等）才需要手填：

1. Discord 客户端 → 用户设置 → **高级设置** → 打开 **开发者模式**
2. 右键目标频道 / 帖子 → **复制频道 ID**
3. 粘到规则弹窗里的「手动添加频道 ID」，点 ➕

### 6. 想转发「别人的服务器」怎么办

你没法把自己的 Bot 拉进别人的服务器。两种办法：

- **对方是公告频道（频道名带 📢，右上角有「关注 / Follow」按钮）**：在你自己的服务器建一个频道 → 到对方频道点 **关注** → 选你的频道。此后对方的消息会自动同步过来，插件监听**你自己这个频道**即可。这是官方支持的方式，最稳。
- **对方是普通频道**：只能请该服务器的管理员用第 4 步的邀请链接把你的 Bot 加进去。

> ❌ 不要用「自己的 Discord 账号 Token」代替 Bot Token。那叫 selfbot，**违反 Discord 服务条款，会被封号**，本插件也不支持。

## 二、插件配置

### 全局设置

| 项 | 说明 |
|---|---|
| Bot Token | 上面第 2 步复制的那串。保存后插件自动拉取频道列表 |
| 使用系统代理 | 国内环境基本要开，走 MoviePilot 的代理设置 |
| 轮询间隔 | 分钟。默认 5；调太小容易被 Discord 限流 |
| 通知类型 | 目标通知渠道里对应的消息类型开关必须是打开的，否则收不到 |
| 失败告警 | 连续 3 次轮询全部失败时推一条告警 |
| 历史保留天数 | 转发历史的清理阈值 |

### 添加规则

一条规则 = 一张卡片，可独立启停。规则弹窗里：

1. **监听频道**：消息从哪来（可多选）
2. **投递去向**（至少选一种，可同时用）：
   - 「推送到通知渠道」开关 + 通知渠道多选（留空 = 全部启用的渠道）
   - 「转发到 Discord 频道」多选 = **频道 → 频道转发**
3. **开关**：
   - **消息聚合** —— 多条新消息合并成一条通知。想让每条码单独一条（方便复制）就关掉
   - **图片转发** —— 转发消息里的第一张图
   - **跳转链接** —— 通知末尾那句「点击查看：…」（由 MoviePilot 通知渠道按跳转链接自动追加）。不想要就关掉
   - **重复检测** —— 内容与近 7 天内已转发过的相同就不再发。**有提取正则时按提取内容判定**，所以同一个礼包码换个说法重发也会被拦掉；没有正则时按消息正文判定
4. **过滤规则**（可选）：关键词白名单 / 屏蔽词 / 作者白黑名单
5. **高级选项**（可选）：提取正则、消息模板、Discord 转发模板

## 三、频道 → 频道转发

在规则里选了「转发到 Discord 频道」，插件就会把命中的消息**重新发**到目标频道。

需要注意：

- Bot 必须在目标频道有 **发送消息** 权限（论坛帖子还需要「在帖子中发送消息」），否则日志报 `HTTP 403`
- 转发出去的内容里 **@everyone、@here、身份组提及会被自动屏蔽**，不会真的 @ 到人
- Discord 单条消息上限 **2000 字**，超出自动截断
- 插件会**跳过 Bot 自己发的消息**，所以 A→B 转发不会被 B 的规则再转回去形成死循环
- 过滤、正则提取、聚合、免打扰对两种去向**一视同仁**，用的是同一套规则
- 两个去向**互不拖累**：通知渠道挂了不影响 Discord 转发，反之亦然；只有失败的那一半会进重试队列下轮重投，成功的不会重复发

### Discord 转发模板

留空用默认：

```
**{channel}** · {author} · {time}
{content}
🎁 {codes}
🔗 {link}
```

支持 Discord 的 Markdown（`**粗体**`、`` `代码` ``、`> 引用`）。变量同下表，`{codes}` / `{link}` 为空时所在整行自动删掉。

## 四、内容提取正则

给规则填一条正则，命中的内容会单独拎出来放进 `{codes}` 变量（通知里单独一行显示，历史表里也有一列）。

配置页正则输入框右边有 **「示例」** 按钮，内置三条可直接点选：

| 示例 | 用途 |
|---|---|
| **礼包码 / Gift Code** | 游戏发码频道。识别 `` `code` `` 反引号写法、`Code: xxx` 冒号写法、`Gift Code` 换行写法 |
| 反引号包裹的内容 | 只取被 `` ` `` 包起来的片段 |
| http/https 链接 | 提取消息里的所有链接 |

### 礼包码示例能认出的写法

```
✨ Gift Code: summer26jp          → summer26jp
✨ Gift Code
summer26jp                        → summer26jp
📌 Code: 47ar5vzKz                → 47ar5vzKz
`summer26jp` `WOS0812` `gogoWOS`  → 三个都提取
```

它**不会**误抓这些：

```
🎁 NEW GIFT CODE AVAILABLE 🎁     → 全大写英文单词，跳过
Code Redeem Now                   → 标签后没有冒号/换行，跳过
Read the Code of Conduct          → 同上
https://wos-giftcode.centurygame.com/   → URL 里的 code，跳过
```

原理：码必须**含数字**或**大小写混排**，且必须跟在 `Code:` / `Code` 换行之后，或者被反引号包着。想自己改的话，正则支持分组，多个分组时取第一个非空的。

## 五、模板变量

| 变量 | 含义 |
|---|---|
| `{channel}` | 来源频道名（`服务器 / #频道`） |
| `{author}` | 发送者，聚合时是去重后的列表 |
| `{content}` | 消息正文（含 Embed、贴纸、投票、转发消息的内容） |
| `{codes}` | 正则提取到的内容，多个用 ` / ` 连接 |
| `{time}` | 消息时间（按 MoviePilot 时区） |
| `{count}` | 本条通知聚合了几条消息 |
| `{link}` | 跳转到 Discord 原消息的链接 |

`{codes}` 和 `{link}` 为空时，**所在的整行会被自动删掉**，不会留下光秃秃的标签。

## 六、其它能力

- 同一频道被多条规则监听时**只拉取一次**消息，不会重复请求
- 过滤链顺序：作者白名单 → 作者黑名单 → 屏蔽词 → 关键词白名单
- 免打扰时段（支持跨零点如 `23:00-08:00`）：时段内暂存，结束后按规则+频道汇总推送
- 首次监听某频道只记录基线，**不会把历史消息刷一遍**
- 积压消息分页拉取，单轮每频道最多 500 条
- 命中 Discord 限流（429）按 `Retry-After` 自动退避重试
- 单条聚合通知最多 20 条消息 / 3000 字，超出自动拆分与截断
- 远程命令 `/discord_check` 手动触发一次检查

## 七、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| **更新插件后界面还是旧的** | 浏览器缓存了旧的 `remoteEntry.js`（模块联邦入口，文件名固定不带哈希，缓存后不会自动更新）。在 MoviePilot 页面按 **Ctrl+Shift+R** 强制刷新；仍不行就 F12 → 右键刷新按钮 →「清空缓存并硬性重新加载」。所有 MoviePilot 的 Vue 插件更新后都要刷这一次 |
| 频道下拉是空的 | 先填 Token 保存，等几秒点「刷新频道列表」；仍为空看日志，多半是代理不通 |
| **消息正文是空的** | 没开 **MESSAGE CONTENT INTENT**，回第 3 步 |
| `HTTP 401` | Token 错了或被重置过，重新 Reset Token 再填 |
| `HTTP 403`（读取时） | Bot 不在该服务器，或缺「查看频道 / 阅读消息历史」权限 |
| `HTTP 403`（转发时） | Bot 在目标频道缺「发送消息」权限；目标是子区/论坛帖还需要「在子区内发送消息」 |
| `HTTP 404` | 频道 ID 填错，或频道已删除 |
| `HTTP 429` | 被限流，把轮询间隔调大一点；插件会自动退避重试 |
| 收不到通知 | 检查 设定→通知 渠道正常，且全局设置选的「通知类型」在该渠道的开关里是打开的 |
| 通知末尾多一行「点击查看：…」 | 这是 MoviePilot 通知渠道收到跳转链接后自动加的，跟模板无关。规则里关掉**跳转链接**开关即可 |
| 同一个码被反复推送 | 打开规则的**重复检测**开关。配了提取正则的话按码判定，换个说法重发也会被拦 |
| 转发到 Discord 没反应 | 确认规则里选了目标频道、Bot 有发言权，看日志里有没有 403 |
| 配置页白屏 | 需要 MoviePilot v2.12+，升级后重装插件 |

## 开发

前端源码在 [`frontend/`](frontend/)（Vue 3 + Vuetify + Vite 模块联邦）。**改完前端必须重新构建**，MoviePilot 加载的是 `dist/assets` 里的产物：

```bash
cd frontend
npm install
npm run build
```

构建产物会输出到 `dist/assets`，需要一并提交。

后端单测在仓库根 [`tests/v2/discordmsgforward/`](../../tests/v2/discordmsgforward/)，`conftest.py` 桩掉了 MoviePilot 主程序依赖，无需 MP 环境：

```bash
python3 -m pytest tests/v2/discordmsgforward -q
```
