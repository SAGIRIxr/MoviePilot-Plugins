# 后宫管理系统（自用版）

管理 MoviePilot 里各个 PT 站点的邀请系统：剩余邀请名额、已邀请用户的状态和分享率健康度。

自用版本，基于 [madrays/MoviePilot-Plugins](https://github.com/madrays/MoviePilot-Plugins)
的「后宫管理系统」重做，适配 MoviePilot v2.14。

## 支持的站点体系

原版只处理 NexusPHP，其余体系一律取数失败。现在按页面指纹识别，站点更换域名也不会失配。

| 体系 | 说明 |
|---|---|
| NexusPHP | 另有憨憨、蝶粉、香岛、麒麟等站点的专用处理器 |
| UNIT3D | 邀请页在 `/users/{用户名}/invites` |
| Gazelle | 邀请页在 `user.php?action=invite` |
| TTG | 名额在页面顶栏 |
| M-Team | 走 API，只需要 API Key |

## 主要改动

- 邀请状态与名额改从发送页判定，不再靠已邀请列表页猜，避免把有权限的站点误报成等级不足。
- 支持浏览器仿真过 Cloudflare：MoviePilot 2.14 起站点访问已换成 CloakBrowser 内核，
  这里补上同样的能力，通行证按域名缓存，失败也会冷却一段时间再重试。
- 支持站点代理、SSL 证书降级、响应编码纠正。
- 站点重名不再互相覆盖（同一个站的新旧域名各建一条时会分开统计）。
- 修正若干解析问题：用户 ID 误匹配、后宫列表取不到、表头行被当成成员、流量值串进分享率列。
- 失败原因分类展示，见下。

## 失败原因

| 提示 | 该怎么办 |
|---|---|
| Cookie 已失效 | 去站点重新登录，更新 MP 里的 Cookie |
| 被 Cloudflare 盾拦截 | 确认配置页开了浏览器仿真；仍不行需升级容器内的 cloakbrowser |
| 域名无法解析 | 站点换域名或已关站，改 MP 里的站点地址 |
| 站点无响应或已关闭 | 站点挂了 |
| 站点返回了跳转/校验中间页 | 站点上了反爬中间页，拿不到真实内容 |
| 站点已关闭邀请系统 | 站点自己关的，有名额也发不出去 |
| 该站点未开放邀请页面 | 站点移除了邀请功能，不是故障 |

## 已知限制

- Cloudflare 配置较严的站点需要容器内 `cloakbrowser` 版本足够新，过旧的版本过不了挑战。
- UNIT3D 的邀请页记录的是邀请码本身，拿不到被邀请人的上传下载，因此只显示接受状态。
- 个别站点的定制版本移除了邀请页，只能如实报「未开放邀请页面」。

## 配置

| 项 | 说明 |
|---|---|
| 启用插件 / 发送通知 / 立即运行一次 | 同原版 |
| 执行周期 | cron 表达式，默认每天 9 点 |
| 选择站点 | 多选，不选则全部站点；增量刷新，失败时保留旧数据 |
| 浏览器仿真过 Cloudflare | 默认开。关掉后遇到 CF 盾直接报错，不开浏览器 |
